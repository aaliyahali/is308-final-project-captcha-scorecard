# CAPTCHA Accessibility Scorecard

**Live site:** https://aaliyahali.github.io/is308-final-project-captcha-scorecard/

## Purpose

CAPTCHAs guard essential online services: account sign-ups, logins, ticket purchases and contact forms. When a disabled user can't get past one, they're locked out of the whole service. This project audits four widely used CAPTCHAs against 10 WCAG 2.2 success criteria and gives developers a practical checklist for choosing and setting up more accessible bot checks.

The audit focuses on the two groups most often blocked:

- **Screen-reader users** (blind and low-vision), tested with VoiceOver on macOS
- **Keyboard-only users** (including people with motor impairments), tested with the mouse disabled

The site has two parts:

1. **Accessibility scorecard:** one page per CAPTCHA (Google reCAPTCHA v2, hCaptcha, Cloudflare Turnstile, and a slider/puzzle CAPTCHA), each rated Pass / Partial / Fail on every criterion, plus a side-by-side comparison.
2. **Developer checklist:** a one-page guide. It starts by asking whether a CAPTCHA is needed at all, then covers lower-barrier options, then the must-haves if a CAPTCHA stays.

The site itself is built to meet WCAG 2.2 AA.

## Suggesting feedback and changes

We welcome corrections, especially from screen-reader and keyboard-only users.

- **Open an issue:** go to the repository's [Issues tab](../../issues/new/choose) and choose **Feedback or suggested change**. Tell us the page, what's wrong, and, if you tested something, the assistive technology, browser and date.
- **Propose an edit directly:** fork the repo, make your change, and open a pull request. Ratings live in `data/captchas.json`; page text lives in `content/`.
- Every page footer links to the feedback form.

We review issues and pull requests and re-test any disputed rating before changing it.

## How the site is built

The site is plain HTML and CSS generated by a small Python script (standard library only). GitHub Actions rebuilds and publishes it to GitHub Pages on every push to `main`.

```
data/criteria.json     The 10 WCAG criteria, groupings and rating definitions (shared)
data/captchas.json     Every rating, note and test detail (Part 1)
content/checklist.html Developer checklist page (Part 2; the page appears once this file exists)
content/home-intro.html Home page intro and stat band
content/methods.html   Methods, limitations and references (appears once this file exists)
static/style.css       Shared stylesheet
build.py               Generates the site into _site/
TESTING-WORKSHEET.md   Protocol for hands-on testing
```

Preview locally:

```
python3 build.py
python3 -m http.server -d _site 8000
```

Then open http://localhost:8000.
